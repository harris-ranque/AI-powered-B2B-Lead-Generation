CONTEXT FOR CHANGES
================================================================================

Background:
- The "enrichment" stage is about finding contact information (emails, phone, etc.)
- The new terminology is clearer: "contacts found" is more specific than "enriched"
- This aligns with the stage title already changed to "Get Contacts"

Architecture:
- Frontend displays data with labels/descriptions
- Backend uses metric keys like "enriched" for tracking
- Label → metric key mapping is in PipelineProgressPanel.tsx (line 60)
- This separation means we can change labels without changing backend

Impact Analysis:
- HIGH: User-facing instructions and button text
- MEDIUM: Dashboard labels and metrics descriptions
- LOW: Help text and tooltips (less user-visible)
- NONE: Backend field names and type definitions
